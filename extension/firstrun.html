Welcome to ClipHutch

Web Media Capture · Your browser's media shelf.

ClipHutch watches the network requests your browser makes on web pages and lists the videos it can detect. Click the toolbar icon to see what's been detected on the current tab; click Download to save a file via Chrome's download manager. Detection and downloading happen entirely on your device. The free tier never contacts a ClipHutch server. If you activate a license, the extension contacts the ClipHutch license-validation endpoint to verify your key, and no other server.

Permissions

Each permission is requested for a specific technical reason. Detection and downloading happen on your device.

webRequest Observes network requests so the extension can detect video URLs as the page loads them. All processing happens on your device.
storage Stores detected video URLs in browser session memory and stores user settings in browser local storage.
downloads Saves detected videos via Chrome's built-in download manager.
offscreen Used briefly to assemble HLS or DASH video segments into a downloadable file.
declarativeNetRequestWithHostAccess When you click Download on an HLS or DASH stream that requires specific request headers (such as a Referer the page sent), a temporary, session-scoped browser rule attaches those captured headers to the extension's own segment fetches. The rule is removed when the download completes, fails, or the tab closes. This is the strictly-weakest declarative-net-request variant: it cannot block or redirect requests, only modify headers, and only on hosts you have already granted access to.
http://*/*
https://*/* 		Required for webRequest to observe network requests across HTTP/HTTPS sites. The extension does not inject content scripts and does not read page DOM content. It does process network request URLs, request headers it observed when the page loaded, and (for tabs where the page loaded a video-shaped network request) that tab's URL and title to associate detected videos with the page they came from.

Both extensions also need broad host_permissions (http://*/*, https://*/*) so webRequest can observe video URLs across sites. The table above compares API permissions, since those determine what code an extension can run on the pages you visit. ClipHutch uses its host access only to observe network requests. It injects no scripts and reads no page content.

Fewer permissions means a smaller surface for trust. The extension can only see what the listed permissions allow, and you can revoke any of them in chrome://extensions at any time.

What this extension does NOT do

  • Send URLs, page titles, hostnames, filenames, or browsing activity to any server.
  • Track usage or include analytics.
  • Inject content scripts.
  • Bypass logins, paywalls, DRM, encryption, or access controls.
  • Decrypt encrypted media streams.
